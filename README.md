
## Getting Started

First, run the development server:

```bash
pnpm install

pnpm dev
```

# Add novo componente

Selecione o componente desejado, enter para instalar

```
pnpm dlx shadcn@latest add
```

## Docker
```
docker build -t nextjs-docker .
```

Run
```
docker run -p 3333:3333 nextjs-docker
```
